ZombieGame:Reborn Changelog
=============================

1.4 - Development version
- 修复玩家死亡时候生存天数数据丢失问题
- 添加更好的调试指令
- 配置文件更具测试调整难度
- 添加配置无限追猎和血月无限追猎，僵尸索敌无限，视野穿墙
- 添加破坏光源的 Goal，可在配置开关
- 修复玩家生存天数死亡后不保存的 bug
- 修复僵尸在陆地转化为溺尸时的 bug
- 添加 TNT Attack 的 Goal 和 ZombieType，以及是否能扔出 TNT 的 Config（不能扔就像普通 Creeper 一样自爆）
- 添加僵尸和溺尸游泳速度分开的 SwimSpeed 修正比
- 添加僵尸免疫方块刺伤，兼容 MineTrap
- 添加僵尸爬梯子
- 优化了僵尸一些AI

1.3 - Official stable release
- 语言文件整理与完善
- 修复一些测试中问题


1.2 - Compatibility update
- 修复血月时间抽搐问题
- 添加新的怪物替换兼容支持


1.1.1 - Hotfix
- 修复初始配置文件无法正常生成的问题


1.1 - Bug fixes
- 修复配置文件无法自动载入的问题
- 修复 NPE 空指针异常
- 修复玩家天数计算错误


1.0 - Initial release
- 完整的 JSON 配置文件系统，支持预设管理、导入/导出
- 10 种僵尸类型 AI 系统：Dummy、Vanilla、Enhanced Vanilla、Builder、Miner、Bow、Crossbow、Shield、Musket Gunner、Guard Villager
- 僵尸装备分发系统（可配置装备类型与附魔）
- 客户端 GUI 配置界面
- 成就系统
- 怪物替换与战利品替换机制
- 时间播报系统（闹钟手动 + 环境自动播放）
- 僵尸猪灵 AI 与发怒机制
- 难度系统按玩家距离动态划分
- 多模组联动框架（外交官模式）
- 区块加载循环卡死修复
